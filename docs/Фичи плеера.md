Экран логина
Залогинить если пароль успешный 
  Если пароль успешный, взять из пришедших с сервера данных название места и поставить его вместо плейхолдера ("Franky") в вёрстку страницы, затем убрать окно логина
При не успешном логина показать надпись ("неправильный пароль")
При успешном логина убирать окно логина не раньше чем 500 миллисекунд (чтобы не было очерэнь резкой вспышки и для юзера все выглядело плавно)

В конце трэка отправляется статистика
Рассчитывается скорость и время скачивания трэка

При смене плейлиста все кнопки временно блокируются (до смены плейлиста. После, кнопки снова разблокируются)
При попытке включить тот же плейлист, который сейчас, смены не происходит, кнопки не блокируются 

Кнопки лайк/дизлайк помечаются цветом при нажатии.
При повторном нажатии попечение их цветом снимается.
(При посещении цветом ещё и заготавливаются данные для отправки из в ат. Повторное нажатие делает речки этих данных. Данные отправляются в конце трэка)
